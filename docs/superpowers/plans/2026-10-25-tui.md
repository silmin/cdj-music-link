# cdj-tui Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development.

**Goal:** `tui/` に Go 製の端末 UI `cdj-tui` を作る。cdj-music-link の API(`/v1/*` と `/v1/stream`)だけを使い、1 画面で「認識している機器」「各デッキの状態」「今かかっている曲」「イベントログ」を見せる。模擬でも Pi 実機でも同じバイナリで動く。

**Architecture:** 単一の Go モジュール(`tui/go.mod`、module `github.com/silmin/cdj-music-link/tui`)、bubbletea v1 + lipgloss + bubbles(viewport)。起動時に `/v1/health` `/v1/devices` `/v1/players` `/v1/master` `/v1/now-playing` でスナップショットを取り、以後 `/v1/stream` を購読して差分更新(切断時は 2 秒後に再接続し、再接続後はスナップショットを取り直す)。`beat` イベント間はクライアント側の時計で位置を進める。

**Tech Stack:** Go 1.27(`go 1.24` 以上を go.mod に)、`github.com/charmbracelet/bubbletea v1.3.10`、`github.com/charmbracelet/lipgloss v1.1.0`、`github.com/charmbracelet/bubbles v1.0.0`。標準ライブラリで HTTP/SSE(`net/http` + `bufio`)。外部 SSE ライブラリは使わない。

**Spec:** API 契約は `openapi/openapi.yaml`。イベントの整形規則は `scripts/emu-watch.sh` と同じ文言にする。

## Global Constraints
- API 以外の情報源を使わない(docker やログを見ない)。`--base http://host:17080` と環境変数 `CDJ_BASE`(既定 `http://localhost:17080`)。
- デッキは `/v1/players` の台数ぶん(1〜4 以上でも)描く。幅に応じて 1 行に 2 枚、収まらなければ 2 段または 1 列にする。
- 端末幅 80 列・高さ 24 行で崩れない。それ未満なら「ターミナルを広げてください」を出す。
- `q` / Ctrl-C で終了。`b` でビートの点滅表示の切替、`w` で波形の表示切替、`l` でログの折り返し切替は任意。
- 依存は上記 3 モジュール(とその推移依存)のみ。`go vet` と `gofmt -l` が無言、`go test ./...` 緑。
- Go のコードにも MIT が適用される(リポジトリ既定)。

## Review Focus
1. SSE の `player` イベントは平らな Player、`track` は `{player, track}`、`beat` の `position` は null になりうる。null 安全を `internal/api` のデコードテストで固定。
2. 端末幅が 80 列のとき 4 デッキでも横にはみ出さない。`internal/ui` の描画テスト(幅 80 で描いて各行の表示幅 ≤ 80)で固定。
3. 再接続後に古い状態が残らない(スナップショットで全置換)。`internal/app` の状態機械テストで固定。

### Task 1: API クライアントと状態モデル(`tui/internal/api`, `tui/internal/model`)
- `api.Client{Base}`: `Health()`, `Devices()`, `Players()`, `Master()`, `NowPlaying()`(`*Player`、null なら nil)、`WaveformPreview(n)`(`heights []int`, `maxHeight`)、`Stream(ctx) (<-chan Event, error)`(SSE パーサ: `event:`/`data:`/`id:`/`retry:`/コメント、空行区切り、CRLF 許容)。
- `model.Event` は `sealed` 風の struct(`Kind` + 各ペイロード)。JSON 型は openapi の名前のまま(camelCase)。
- `model.State`: `Online bool`, `DeviceNumber *int`, `Devices []Device`, `Players map[int]Player`, `Master`, `NowPlaying *Player`, `Beats map[int]LastBeat{At time.Time, PositionMs *int64, BeatWithinBar, Tempo}`, `Log []string`(上限 500 行)。`Apply(ev)` が差分適用、`ReplaceSnapshot(...)` が全置換。
- テスト: 実 JSON 断片(openapi の例に合わせた固定文字列)でデコード、`position: null` と `track: null` と `isOnAir: null`、`PlayerEvent` が平らな Player であること、SSE パーサが `retry:` と複数行 `data:` と CRLF を扱うこと、`ReplaceSnapshot` 後に古いプレイヤーが消えること。

### Task 2: 画面(`tui/internal/ui`, `tui/cmd/cdj-tui`)
- bubbletea の `Model`: `tea.WindowSizeMsg`、SSE イベント(`tea.Cmd` で chan を読む)、1 秒ティック(時計・位置の補間)、キー。
- レイアウト(lipgloss): ヘッダ 1 行(`cdj-music-link  ●online  player 3   devices: 1 CDJ 2 CDJ 4 CDJ-2000nexus   HH:MM:SS`; オフラインは `○offline` を赤)。NOW PLAYING 枠(曲名・アーティスト・キー・BPM、進行バー `mm:ss ▕████░░░░▏ mm:ss`、`bar N  beat ●○○○`)。デッキ枠を幅で並べる(各枠: 見出し `player N  playing|paused|cued|empty  [MASTER] [ON AIR]`、`id  "title"  key  BPM`、`mm:ss / mm:ss   pitch ±x.xx%`、波形 1 行(プレビュー `heights` を `▁▂▃▄▅▆▇█` に量子化し、現在位置の列を反転)、曲なしは `(no track)`)。イベント枠(残り高さ、`bubbles/viewport`、新着で末尾追従)。
- 波形は曲が変わったときだけ `WaveformPreview(n)` を取り直す(`track.id`+`waveformAvailable` が変化したとき)。取得失敗は無視して空行。
- 位置の補間: 直近の `beat` の `position.ms` と受信時刻から、`isPlaying` のとき `経過 ms × (1 + pitch/100)` を足す。`position` が null のデッキは `--:--`。
- イベントログの文言は `scripts/emu-watch.sh` と同じ(`player 1  track loaded  id=308 from device 4 (usb, rekordbox)`、`player 1  metadata  "…" — artist  key  BPM  m:ss`、`now playing → …`、`device 4 connected …`、`link online/offline`、`tempo master → …`)。`now playing →` は `/v1/now-playing` を player/track/master イベント後に 300 ms デバウンスで引いて変化時のみ。
- テスト: 幅 80・高 24 で 1〜4 デッキを描いて各行の `lipgloss.Width` ≤ 80、行数 ≤ 24; 幅 60 なら案内文のみ; 波形量子化(`heights` 1200 → 幅 36 列への縮約と現在位置の列)。
- `cmd/cdj-tui/main.go`: フラグ `--base`、`CDJ_BASE`、`-h`。

### Task 3: 配線とドキュメント
- `tui/README.md`(起動方法、キー、画面の読み方、模擬との組み合わせ: `scripts/emu-watch.sh --no-scenario` ではなくシナリオ有効のまま別ターミナルで `go run ./cmd/cdj-tui`)。トップ `README.md` に 3 行。
- CI: `.github/workflows/ci.yml` の `test` ジョブに `actions/setup-go@v5`(go-version-file `tui/go.mod`)と `cd tui && gofmt -l . && go vet ./... && go test ./... && go build ./cmd/cdj-tui` を追加。
- `.gitignore` に `tui/cdj-tui`(ビルド成果物)。
